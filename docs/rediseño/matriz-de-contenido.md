# Matriz de contenido · Plantilla V02

Gerencia de Proyectos es el primer caso de la plantilla. La matriz sigue el orden del prototipo e identifica qué se conserva, qué se completa para cada lanzamiento y qué queda por validar. Por ahora, todos los bloques forman parte de cada landing. [Brief de rediseño](brief.md)
